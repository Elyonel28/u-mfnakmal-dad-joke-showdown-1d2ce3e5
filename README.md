One dad joke, 94 characters, entered in make.fun's "Dad Joke Showdown" bounty ($5 in USDC).

> I asked my phone charger why it keeps wandering off. It said it's just trying to stay current.

The program writes exactly that joke to `/output/entry.txt`. It checks the joke first (1–200 characters, a single line, not only whitespace), writes it, then reads the file back to confirm the round-trip.

## Run it

```sh
node main.ts
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory (default `/output`).
